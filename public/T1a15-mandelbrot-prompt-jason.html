The Mandelbrot Fractal

This mesmerizing geometry is generated in the complex number plane using a deceptively simple iterative formula:

Zn+1 = Zn2 + C

For every pixel, we set Z0 = 0 and map the screen coordinate to the constant complex number C. We repeat the equation up to 300 times.

If the value spirals off to infinity, the speed at which it escapes determines its vibrant color cycling. If it stays bounded forever, it belongs to the black heart of the fractal set.
