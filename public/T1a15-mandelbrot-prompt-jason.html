The Mandelbrot Set

This fractal is generated by iterating a simple mathematical formula for every pixel on the screen:

Zn+1 = Zn2 + C

Where C is a constant complex number corresponding to the point's position on the complex plane, and Z starts at zero.

If the value of Z stays bounded (never escapes to infinity) after many iterations, the point belongs to the Mandelbrot set and is colored black. If it escapes, it is dynamically colored based on how quickly it blew up!
